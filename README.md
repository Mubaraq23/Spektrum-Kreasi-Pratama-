# Spektrum Kreasi Pratama 3.0 (KAN LK-291-IDN)

Aplikasi Web Manajemen Metrologi & Kalibrasi Digital Terpadu KAN ISO/IEC 17025 & BAPETEN.

## Panduan Pengoperasian Lokal

**Prasyarat:** Node.js (v18+)

1. Install dependencies:

   ```bash
   npm install
   ```

2. Pengaturan Variabel Lingkungan:

   Atur `GEMINI_API_KEY` pada file `.env.local`.

3. Jalankan server pengembang lokal:

   ```bash
   npm run dev
   ```
